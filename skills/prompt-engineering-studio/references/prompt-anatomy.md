# 提示词七大要素拆解

> 一条好 prompt 通常由以下要素组成。缺哪块，就补哪块。

| 要素 | 作用 | 常见写法 | 是否必填 |
|---|---|---|---|
| 角色 Role | 锚定身份与口径，收敛输出风格 | "你是一位资深{职业}" | 强烈建议 |
| 任务 Task | 明确要做什么，动词开头 | "请{动词}……" | **必填** |
| 上下文 Context | 提供背景，避免 AI 瞎猜 | "背景是……""用户是……" | 建议 |
| 约束 Constraints | 划定边界：字数/禁项/必含/语言 | "不超过{数字}字""不要……" | 强烈建议 |
| 输出格式 Format | 规定长相：表格/列表/JSON/Markdown | "用表格输出""返回 JSON" | 建议 |
| 示例 Example | 少样本，给 1–3 个样例 | "示例：输入 A→输出 B" | 可选（强效） |
| 语气 Tone | 正式/轻松/口语/专业 | "语气轻松友好" | 可选 |

## 要素优先级（评分用）
- 任务明确度 = 权重最高（没说清要干嘛就废了）
- 角色 + 约束 = 次高（决定输出是否对口、是否可控）
- 上下文 + 格式 + 示例 = 提升稳定性与可复用性
- 语气 = 微调观感

## 反模式（新手常踩）
- ❌ 一句话带过："帮我写个文案" → 没有角色/约束/格式，产出随机。
- ❌ 堆砌形容词："写得高级一点、专业一点、有质感" → 不可执行。
- ❌ 矛盾约束："简短但详细""口语但正式" → AI 左右为难。
- ❌ 无示例又要求特定格式 → 格式经常跑偏。
- ✅ 改为：角色 + 明确动词 + 具体约束 + 格式 + （示例）。

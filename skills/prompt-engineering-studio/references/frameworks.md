# 主流提示词框架（选用指南）

> 把"想到哪写到哪"升级为"结构化表达"。三套框架覆盖绝大多数场景，按需取用。

## 1. CO-STAR（最通用，推荐首选）
适合：绝大多数写作、分析、生成类任务。
- **C**ontext 上下文——背景与现状
- **O**bjective 任务——要 AI 做什么（动词开头）
- **S**tyle 风格——模仿谁/什么文体
- **T**one 语气——正式/轻松/严谨
- **A**udience 受众——写给谁看
- **R**esponse 格式——输出长什么样

## 2. CRISPE（重角色与能力）
适合：需要 AI 扮演专家、做复杂推理的任务。
- **C**apacity & **R**ole 能力与角色
- **I**nsight 背景洞察
- **S**tatement 任务陈述
- **P**ersonality 个性语气
- **E**xperiment 多方案实验

## 3. RISEN（重约束与示例）
适合：需要强约束、可复现、含示例的任务（如分类、提取、格式化）。
- **R**ole 角色
- **I**nstruction 指令
- **S**upplementary 补充信息
- **E**nd goal 终极目标
- **N**arrowing 约束收窄
- 另加 **Example / Specification** 示例与规范

## 怎么选
| 你的情况 | 首选框架 |
|---|---|
| 写文章/做分析/要产出 | CO-STAR |
| 要 AI 当专家做推理 | CRISPE |
| 要格式稳定/可复现/有示例 | RISEN 或 CO-STAR + 示例 |
| 完全没思路 | CO-STAR 全覆盖 |

## 通用加分项（任何框架都该加）
1. **角色锚定**：明确"你是谁"，收敛风格与口径。
2. **任务动词化**：用"总结/对比/列出/改写为"等明确动词。
3. **约束显式**：字数、禁项、必含项、语言、格式。
4. **少样本（few-shot）**：给 1–3 个输入输出样例，效果立竿见影。
5. **分步思考**：复杂任务加"先列提纲再展开"或"一步步思考"。
6. **防幻觉**：要求"不确定就说明，不要编造"。

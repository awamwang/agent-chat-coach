# 多行业 Before / After 案例（中性行业，禁金融味）

> 用四个中性行业演示"从烂 prompt 到好 prompt"。每个都可直接套用本 skill 的框架复现。

## 案例 1：效率 App 用户调研提纲
**❌ Before**（太泛）
> 帮我写个用户访谈的问题。

**✅ After**（CO-STAR 全覆盖）
> 你是一位资深 UX 研究员。背景：我们刚上线一款番茄钟效率 App「Focus25」，想找 10 位重度用户做深度访谈。任务：设计一份 8–10 题的半结构化访谈提纲，覆盖使用动机、痛点、留存与付费意愿。约束：每题附"追问建议"，总字数不超过 600 字，用中文。风格：专业但不学术。语气：中性客观。受众：内部产品团队。输出格式：编号列表，每题为"主问题 + 追问"。

## 案例 2：咖啡店新品社媒推文
**❌ Before**
> 写个小红书文案，卖我们的新品燕麦拿铁。

**✅ After**（角色 + 约束 + 格式）
> 你是一位懂年轻人口味的小红书生活方式博主。背景：本店新推「燕麦丝绒拿铁」，低卡、奶香顺滑、限时第二杯半价。任务：写一篇种草笔记，带 3 个真实使用场景。约束：标题带 emoji、正文不超过 200 字、文末附 3 个相关话题标签，语气轻松有网感。输出格式：标题 + 正文 + 标签三段。

## 案例 3：在线课程大纲
**❌ Before**
> 给我做个 Python 入门课的大纲。

**✅ After**（CRISPE 思路）
> 你是一位有十年经验的编程讲师。背景：学员为零基础上班族，每周能投入 3 小时，目标是 8 周后能写自动化脚本。任务：输出一份 8 周课程大纲，每周含"目标 / 知识点 / 一个小项目"。约束：避免 jargon，每节课不超过 5 个核心概念，用中文。输出格式：表格（周次 / 目标 / 知识点 / 项目）。

## 案例 4：电商零食详情页
**❌ Before**
> 写个商品描述。

**✅ After**（RISEN + 示例）
> 你是一位转化率导向的电商品牌文案。任务：为「海盐黑巧克力脆片」写一版详情页文案。补充信息：原料进口可可、0 反式脂肪、独立小包装。约束：突出"解馋不胖"卖点，含 3 个卖点 + 1 句行动号召，不超过 120 字。示例：输入"坚果混合包"→输出"每日一把，饱腹不罪恶。独立锁鲜，随身解馋。现在囤，立省 20%。"输出格式：卖点列表 + 行动句。

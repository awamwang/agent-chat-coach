# 反例对照库

用户明显在犯典型错误时，调出对应场景。固定格式——**展示改造过程，不只给成品**。

---

## 场景 1：全模糊型

```
❌ 坏 prompt：帮我写点东西
🔍 诊断：五维全缺（Role/Context/Task/Format/Constraint）

→ 第1步：补 Task（你要写什么？）
  "帮我写个周报"

→ 第2步：补 Context（什么岗位？给谁看？）
  "我是产品经理，周报给直属老板看"

→ 第3步：补 Format（多长？什么结构？）
  "分本周完成/下周计划/需支持三段，每段3条以内"

→ 第4步：补 Role（让 AI 扮演什么角色？）
  "你是一位擅长向管理层汇报的资深员工"

✅ 最终版：你是一位擅长向管理层汇报的资深员工。我是产品经理，本周做了用户调研和需求评审。请帮我写周报，分「本周完成/下周计划/需支持」三段，每段不超过3条。
🔑 改造路径：Task → Context → Format → Role，每步补一个维度，从全模糊到可直接用。
```

## 场景 2：无角色型

```
❌ 坏 prompt：写个招聘启事
🔍 诊断：缺 Role（AI 不知道用什么口吻写）

→ 补 Role：
  "你是一位资深HR，擅长写吸引人的招聘文案"

✅ 最终版：你是一位资深HR。请帮我写一份招聘启事，岗位是 [xxx]，面向 [受众]，要求突出公司亮点和岗位成长性，不超过200字。
🔑 差别：加了角色后，AI 会用 HR 视角写，不是泛泛的模板。
```

## 场景 3：无场景型

```
❌ 坏 prompt：写一个招聘启事
🔍 诊断：缺 Context（什么公司？什么岗位？什么阶段？）

→ 补 Context：
  "我们是一家20人的创业公司，招前端工程师，预算有限但成长空间大"

✅ 最终版：你是一位资深HR。我们是一家20人的创业公司，正在招前端工程师，预算有限但成长空间大。请写一份招聘启事，突出灵活性和成长机会，不超过200字。
🔑 差别：加了场景后，AI 不会写"世界500强""行业领先"这种不匹配的说辞。
```

## 场景 4：无格式型

```
❌ 坏 prompt：分析下这个市场
🔍 诊断：缺 Format（要多长？什么结构？一段话还是一份报告？）

→ 补 Format：
  "用3个要点列结论，每个要点配一句话说明，不超过300字"

✅ 最终版：你是一位市场分析师。请分析 [行业] 市场，用3个要点列核心结论，每个要点配一句话说明，不超过300字。不要编造具体数据，不确定的地方标注"需验证"。
🔑 差别：加了格式后，AI 不会给你一篇3000字的散文。
```

## 场景 5：一次性堆料型

```
❌ 坏 prompt：帮我写个方案要包括市场分析竞品分析用户画像营销策略预算规划风险评估时间线和KPI，要专业但不能太长要有数据支撑但不用找数据用估算就行
🔍 诊断：一句话塞 8 个要求，AI 抓不到重点

→ 拆成 2 个 prompt：
  Prompt A（分析部分）：你是一位市场分析师。请做 [行业] 的市场分析+竞品分析+用户画像，每个部分3个要点，不超过500字。
  Prompt B（策略部分）：你是一位营销策划。基于上面的分析，做营销策略+预算+KPI，表格输出，不超过300字。

✅ 拆完后每个 prompt 任务明确，AI 能聚焦。
🔑 改造路径：做减法——拆分任务，每个 prompt 只干一件事。
```

## 场景 6：反面否定型

```
❌ 坏 prompt：不要写太长不要用术语不要分点不要正式语气
🔍 诊断：只说不要什么，不说要什么。AI 知道不做什么，但不知道做什么。

→ 补正面指令：
  "用大白话写，像跟朋友聊天一样，一段话说完，不超过100字"

✅ 最终版：你是一位懂 [领域] 的朋友。用大白话给我解释 [概念]，像聊天一样自然，一段话说完，不超过100字。不要用专业术语。
🔑 差别：先说要什么，再说不要什么。正面指令优先于反面指令。
```

## 场景 7：追问放弃型

```
❌ 用户行为：AI 回答模糊后，用户直接放弃不追问
🔍 问题：AI 答得模糊不是AI的错，是 prompt 不够具体。放弃追问 = 放弃修复机会。

→ 教用户追问模板：
  "你上面说的 [具体部分] 太笼统了，能不能展开讲？给个具体例子。"

✅ 正确做法：AI答得模糊 → 追问"展开讲+给例子" → AI补充 → 继续往下。
🔑 差别：追问是修复prompt的最低成本方式，比重写整个prompt快得多。
```

## 场景 8：幻觉全信型

```
❌ 用户行为：AI 编了数字或引用，用户直接用不核对
🔍 问题：AI 会一本正经编造看起来真实的数据。

→ 教用户核查：
  "你上面这个 [数字/引用] 是从哪里来的？如果不确定请明说。"

✅ 正确做法：AI 给了具体数字/引用 → 回问来源 → AI 说不确定 → 自己去原始来源核对。
🔑 差别：不是不信AI，是用AI给的方向去找真实数据。
```

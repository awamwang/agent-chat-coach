# 完整陪练示例（4 轮）

从诊断到迭代到收尾的全流程演示，按 V1.0.5 的交付规则（增量输出 + diff 表 + 验收）更新。

---

## 第 1 轮

**用户**：帮我写个周报

**Agent Buddy**：
```
👀 先诊断，看你这句 prompt 缺什么：

- ❌ 缺角色（AI 不知道从谁的视角写）
- ❌ 缺场景（不知道你什么公司什么岗位）
- ❌ 缺任务细节（本周做了啥没说）
- ❌ 缺格式（要多长、什么结构没说）
- ❌ 缺约束（要不要带数据、能不能有废话没说）

覆盖 0/5，评分 0/10——五维全空白，属于新手层，先补最关键的三样。

先问 3 个关键的：

1. 你在什么岗位、面向谁写？（老板 / HR / 团队）
2. 本周主要做了哪 2-3 件事？
3. 想要多长？（100 字 / 300 字 / 500 字）

3 个都告诉我，我给你三档 prompt，你挑一个用。
```

---

## 第 2 轮

**用户**：我是产品经理，面向直属老板，本周做了用户调研、竞品分析、需求评审

**Agent Buddy**：
```
信息够了，评分 5/10（有 C₁、T，缺 R/F/C₂）。按默认交付方式，先给你 Standard 全文，Lite 和 Pro 只列差异：

Lite（最小改动）：
在原句上只补 2 处——加"面向直属老板"（场景）+ 加"分三段：本周完成/下周计划/需要支持"（格式）。适合 5 分钟内要用的场景。

Standard（五段式完整）：
你是一位擅长向管理层汇报的资深员工。我是产品经理，本周主要做了用户调研、竞品分析、需求评审。请帮我整理成周报，分「本周完成/下周计划/需要支持」三段，每段用要点列表，全篇不超过 300 字。不写空话套话，必须带数字或具体产出。

Pro（进阶精修）：
在 Standard 基础上加 ① few-shot 输出骨架（## 本周完成 - [事项]：[结果/数据] …）② 一句思维链引导（"先想想老板最关心什么，再决定哪些放前面"）。适合长期复用。

💡 原理（diff 表）：
| 段 | 原句 → 新句 | 为什么 |
|---|---|---|
| R | （无）→ 资深员工 | 加了角色，AI 会用汇报视角写，不是泛泛模板 |
| C₁ | 我是产品经理 → +面向直属老板 | 知道用管理语言，不会太技术 |
| F | （无）→ 三段/要点/300字 | 输出直接能用，不用再排版 |
| C₂ | （无）→ 不写空话/带数字 | 不会出一堆正确的废话 |

挑一档拿去用。AI 要是还答得不对，回来告诉我具体哪里不对。
```

---

## 第 3 轮

**用户**：Standard 版用了，AI 写得还行但太啰嗦了

**Agent Buddy**：
```
👀 "太啰嗦"→ 这是 Format 的问题，不是整个 prompt 的问题。

只改 Format 段，把"全篇不超过 300 字"改成：

"分三段，每段最多 2 条要点，每条不超过 30 字，全篇不超过 200 字。"

其他段不用动。

💡 为什么只改这里：你的 prompt 方向是对的（AI 写得还行），只是长度没卡死。Format 段是控制长度的开关，改这里最精准。改其他段反而可能把好的地方改坏。

✅ 验收：改完跑一次——输出是不是控制在 200 字内、每段 ≤2 条？命中就收工；没命中把 AI 的实际输出贴回来，我帮你继续定位。
```

---

## 第 4 轮

**用户**：好多了，谢谢

**Agent Buddy**：
```
👍 下次你可以直接用五段式自己写：
R-角色 / C₁-场景 / T-任务 / F-格式 / C₂-约束

记住 R+T+F 三段就打败 80% 的模糊 prompt。你这次已经能自己定位"长度问题在 F 段"，下次碰到类似情况可以先自查。

想练手随时说"出题"，我出个 prompt 你来改。碰到写不好的随时来找我。
```

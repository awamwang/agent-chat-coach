# 进阶技巧

用户已经能自己写出完整 RCTFC prompt 后，教以下技巧。新手不教，避免信息过载。

---

## 1. 思维链引导

> 源自 Wei et al., 2022

在 prompt 末尾加"请一步步思考再给结论"，AI 会展示推理过程，减少跳步错误。

```
适用：逻辑推理、数学计算、多步决策
示例：...请先一步步分析每个选项的利弊，再给最终建议。
```

---

## 2. Few-shot 示例

> 源自 Brown et al., 2020

给 AI 1-2 个"输入→输出"的示例，AI 会模仿格式和风格。

```
适用：需要特定格式输出、风格统一场景
示例：
输入：[示例输入A] → 输出：[示例输出A]
输入：[示例输入B] → 输出：[示例输出B]
输入：[实际输入] → 输出：
```

---

## 3. 分步拆解

复杂任务不要一个 prompt 搞定，拆成 2-3 步：

```
第一步要大纲 → 确认后 → 第二步要正文 → 确认后 → 第三步润色
适用：写长文、做方案、复杂分析
```

---

## 4. 反向约束

不只说"要什么"，也说"不要什么"。注意：正面指令在先，反面约束在后。

```
"不要用'首先其次最后'这类模板化过渡词"
"不要编造具体数字，不确定的标注'需确认'"
适用：AI 输出太"AI味"时
```

---

## 5. 角色对话法

让 AI 扮演两个不同角色互相讨论，从多个角度看问题：

```
"请你同时扮演一个乐观的产品经理和一个挑剔的技术负责人，讨论 [话题] 的可行性，最后给出共识结论。"
适用：需要多角度分析、打破思维定式时
```

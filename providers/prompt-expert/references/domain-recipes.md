# 六大赛道铸造配方（知识截止：2026-09）

> 用途：Stage 2 赛道定位时按配方取「五层要点 + 高频变量 + 专属约束」。配方给骨架与弹药，最终成品仍按五层黄金架构组装并过评分门禁。

---

## 配方一：通用写作 / 文案

- **L1 身份**：具体文体 + 年限 + 服务对象（如「深耕小红书美妆赛道 5 年的爆文操盘手，服务国货品牌」）。
- **L2 任务**：文体 + 主题 + 篇幅 + 数量（如「产出 3 版标题 + 1 篇 800 字正文」）。
- **L3 约束**：禁用词表（「颠覆」「革命性」「绝绝子」按受众裁剪）、平台违禁词、事实红线（数据必须有来源）。
- **L4 变量**：`{产品名}` `{卖点}` `{受众}` `{平台}` `{竞品}` `{活动信息}`。
- **L5 格式**：标题行数、正文分段规则、是否给封面文案与标签。

## 配方二：代码与开发

- **L1 身份**：语言 + 技术栈 + 资深度（「15 年 Python 后端，Django/PostgreSQL 专精，遵循 PEP8」）。
- **L2 任务**：输入（代码/报错/需求）+ 输出（可运行代码 + 修改点清单 + 测试建议）。
- **L3 约束**：不得引入未声明依赖；不改需求外行为；错误处理必写；版本兼容声明。
- **L4 变量**：`{语言}` `{框架版本}` `{现有代码}` `{报错信息}` `{运行环境}`。
- **L5 格式**：代码块标语言；先给结论（根因/方案）再给完整代码；变更点用列表。
- **特化**：加 P8 分步推理——「先复述问题与根因假设，再给修复」。

## 配方三：营销与增长

- **L1 身份**：渠道专精（信息流/SEO/私域）+ 行业 + 业绩背景。
- **L2 任务**：目标（转化/获客/留存）+ 交付物（方案/脚本/落地页文案）+ 衡量口径。
- **L3 约束**：禁绝对化用语（广告法口径）、禁夸大承诺、数据引用必须可溯源。
- **L4 变量**：`{渠道}` `{预算}` `{客单价}` `{目标人群}` `{转化目标}`。
- **L5 格式**：策略结论先行 + 执行清单（步骤/负责人/周期）+ 风险提示。

## 配方四：教育与讲解

- **L1 身份**：学科 + 教龄 + 受众适配力（「高中物理特级教师，擅长把抽象概念讲到零基础能懂」）。
- **L2 任务**：知识点 + 受众水平 + 目标（听懂/会做/能讲给别人）。
- **L3 约束**：先类比后术语；公式必须配文字解释；禁用超纲概念不解释；例题数据需自洽。
- **L4 变量**：`{知识点}` `{受众}` `{已有基础}` `{课时}`。
- **L5 格式**：引入 → 类比 → 原理 → 例题 → 常见误区 → 小结；每节标题化。

## 配方五：数据分析

- **L1 身份**：行业数据分析师 + 工具链（SQL/Python/Excel）+ 业务口径熟悉度。
- **L2 任务**：输入数据 + 分析问题 + 决策用途（给谁看、支撑什么决定）。
- **L3 约束**：口径定义先行（统计范围/时间窗）；样本不足必须声明；不臆测因果（相关≠因果）；数字必须可由给定数据复算。
- **L4 变量**：`{数据文件}` `{统计口径}` `{时间范围}` `{业务背景}`。
- **L5 格式**：结论摘要（3 条以内）→ 明细表 → 方法说明与局限。
- **特化**：强制「先给口径确认问题清单（若有歧义），无歧义则直接输出」二选一路径。

## 配方六：Agent / 技能系统提示词（铸造提示词的提示词）

在五层之上按「系统提示词特化」追加（详见 prompt-architecture.md 第三节）：触发层、流程层（Stage 化）、规范层、边界层。
- **L1 身份**：Agent 名称 + 专业定位 + 信条一句（定调用）。
- **L2 任务**：输入→处理→交付物的完整任务流。
- **L3 约束**：权限最小化、敏感操作先确认、禁编造字段/事实。
- **L4 变量**：外部依赖（API/文件路径）全部 `${VAR}` 占位。
- **L5 格式**：正文祈使句 + 参考资料引用不嵌套 + 异常降级路径。
- **特化**：务必写「异常与降级」节与「铁律」节——这是系统提示词稳定性的最大杠杆。

## 速用骨架（复制即改）

```text
## 角色身份
你是【{领域}】的资深【{角色}】，{深度词}，仅处理【{边界}】相关问题；领域外问题回复：该问题超出我的服务范围。

## 核心任务
基于下方【参考素材/变量】，{动作动词}{交付物}，完成标准：{数量/质量线}。

## 强制约束
1. 仅基于给定素材，不知道就说不知道，严禁编造；
2. {风格约束：语气/受众/长度}；
3. 禁用：{禁用词表/句式}。

## 参考素材
{素材 或 ${变量1}、${变量2}（变量表见附注）}

## 输出格式
{结构类型 + 分段规则 + 长度 + 重点标注方式}；交付前自检：{自检清单}。
```

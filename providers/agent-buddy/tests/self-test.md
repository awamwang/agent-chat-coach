# 自测集（发版前回归）

每次发版前，用下表 20 条输入人工过一遍：以下输入均假设用户已通过显式点名（agent-buddy / 教练 / 陪练）进入陪练模式，除非特别注明「未点名」。输入 → 期望走的路由 → 期望的输出形态。任何一条跑偏都说明路由逻辑被改坏了。路由规则见 `SKILL.md`。

| # | 输入（用户消息） | 期望路径 | 期望输出形态 |
|---|---|---|---|
| 1 | "帮我改prompt"（没给内容） | 完整路径 | 先追问（≤3 个问题），不诊断不改写 |
| 2 | "帮我看看这个prompt：写个招聘启事" | 评价路径 | 只五维诊断 + 打分 + 2-3 条方向，不改写；结尾问"要不要改一版" |
| 3 | "帮我写个周报" | 完整路径 | 第0步无歧义 → 诊断（覆盖 0/5 + 打分）+ 追问 3 个 → 交付 Standard 全文 + Lite/Pro 差异 + diff 表 |
| 4 | "写个招聘启事" | 完整路径 | 命中五段式模板（场景检测），交付模板 + 易错点 |
| 5 | "写条文案推广我们的产品" | 完整路径 + 场景技法 | BAB 说服链融入，原理提到技法名 |
| 6 | "A方案还是B方案，帮我决策" | 完整路径 + 场景技法 | 多视角对比融入 C₂ 段 |
| 7 | "详细但要简短"（约束矛盾） | 第0步意图歧义 | 直接指出矛盾，让用户取舍，不做诊断 |
| 8 | "帮我做个客户分析"（有歧义） | 第0步意图歧义 | 列出 ≥3 种解读（覆盖产出物+方法论两方向），反问 |
| 9 | "别问了，直接给我模板" | 快速路径 | 直接给模板 + 一句提醒，不追问 |
| 10 | "帮我润色这句话：……"（陪练模式内） | 快速路径 | 直接给润色版（内部路由识别到润色意图） |
| 11 | "AI答得不对" + 具体 AI 输出（陪练模式内） | 迭代式教学 | 定位根因段 → 只改那段 → 讲连带 → 给验收问题 |
| 12 | "出题考考我" | 出题模式 | 从反例库出 1 道题，用户改写后按五维打分点评 |
| 13 | "帮我测一下这个prompt"（宿主有工具） | 实测模式（opt-in） | 跑 3 次看方差 + 核实引用/代码，结果并入诊断；无工具则说明"只教不测" |
| 14 | 熟练用户 prompt（五段齐全） | 层级速判=熟手 | 只微调 1-2 处，不啰嗦讲原理，可带进阶技巧 |
| 15 | "这段能不能发给AI"（含敏感信息） | 隐私安全 | 提醒敏感信息，默认"不确定就不发" |
| 16 | 违法违规内容（伪造证件等） | fallback #3 | 明确拒绝优化，不做 workaround |
| 17 | 用户情绪化（"这破AI什么都干不了"） | fallback #11 | 先共情一句，再引导贴出原话和 AI 输出 |
| 18 | "/agent-buddy 帮我写份外贸业务员半年度工作总结"（显式点名） | 最高优先级规则 | 进入陪练：给"写总结"的提示词（场景检测/快速路径），不直接代写；结尾可问"要不要按提示词直接写"；安全红线内容除外 |
| 19 | "帮我写份总结"（未点名） | 不进入陪练 | 不响应 / 直接回答（验证日常业务任务不会误触发） |
| 20 | "措辞一下这段话"（未点名） | 不进入陪练 | 不响应 / 直接回答（验证日常高频词不会误触发） |

**回归检查点**：
- [ ] 未点名时绝不自动加载（日常高频词如"润色/措辞/写总结"不触发）
- [ ] 显式点名后绝不退出陪练（安全红线除外）
- [ ] 评价路径从不主动改写
- [ ] 完整路径从不输出三份全文（只有用户点名才展开 Lite/Pro 全文）
- [ ] 诊断末尾必有覆盖总结 + 打分（0-10，带扣分点）
- [ ] 迭代式教学每次只改 1 段（连带最多 2 段）且带验收问题
- [ ] 实测模式只在三条件全满足时进入
- [ ] 出题模式交卷必有打分
- [ ] 所有跨文件引用（references/ 路径）真实存在

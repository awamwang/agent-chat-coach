# 幻觉识别训练

告诉用户：**AI 一本正经胡说八道**主要出现在这些地方，看到必须核对。

---

## 5 类必核对内容

1. **具体数字**：市场规模、增长率、销售额——去原始来源核对
2. **人名 + 事件**："XX 在 XXXX 年说过 XXX"——去权威渠道验证
3. **法律条款 / 政策**：条文编号、生效日期——去官方文件对
4. **引用出处**：书名、论文、网址——AI 给的 URL 打开确认存在
5. **代码 API**：某个库的函数名、参数——去官方文档确认，小众库更容易编

---

## 万能追问

教用户一句万能追问：

> 「你上面这个 [数字/引用/API] 是从哪里来的？如果不确定请明说。」

---

## 核查工具建议

| 类型 | 核查渠道 |
|------|---------|
| 数字类 | 原始报告 / 统计局 / 行业协会数据 |
| 引用类 | Google Scholar / 知网搜论文标题确认存在 |
| 法条类 | 北大法宝 / 国家法律法规数据库 |
| API 类 | 官方文档 / MDN / Stack Overflow 高赞回答 |

---

## 教用户的要点

- 不是不信 AI，是用 AI 给的方向去找真实数据
- AI 给的具体数字和引用是"线索"不是"事实"
- 重要场景（法律、财务、医疗）必须人工核对

# 交互模式指导

告诉用户：不同任务用不同的对话模式。

---

## 三种模式

| 模式 | 什么场景 | 特点 |
|------|---------|------|
| **一次性问答** | 明确的单点问题（如"Python list 怎么去重"） | 一问一答，问清楚就行 |
| **多轮协作** | 需要迭代的任务（写文案、做方案、改代码） | 分步给 AI，每步确认再往下 |
| **Agent 工具链** | 需要调外部数据或工具的复杂任务 | 用带工具的 Agent，别硬让纯聊天模型干 |

---

## 怎么帮用户判断

- 用户问"XX 是什么 / 怎么做" → 一次性问答
- 用户说"帮我写 / 做 / 设计 XX" → 多轮协作
- 用户说"帮我分析这份数据 / 这个网页 / 这个代码库" → Agent 工具链

关键一条：**能用工具的让 Agent 干，别硬让聊天模型干。**
